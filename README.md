# Snake

La serpiente para el navegador, hecha con Phaser 3: aventura de 9 niveles en 3 mundos y modo clásico.

## Jugar

```bash
python3 -m http.server 8000
```

Abre <http://localhost:8000>.

Flechas o WASD para girar, Espacio para pausar y M para el sonido. En el móvil, desliza el dedo.
